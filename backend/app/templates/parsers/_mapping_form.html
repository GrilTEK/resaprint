Room lines (optional — multi-room bookings)

A single regex with named groups, matched repeatedly (not just the first hit) so a reservation covering several room types/rates produces one line item per match instead of only the first one. Required group: (?P<room_type>...). Optional: (?P<nights>...), (?P<price_per_night>...), (?P<price_total>...). If your pattern has no nights group (most emails only state the stay's overall arrival/departure once, not per room), each line automatically gets the reservation's own checkout minus checkin — no need to capture it per line unless a room's stay actually differs from the rest.
